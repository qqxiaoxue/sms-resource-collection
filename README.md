# 资源收藏站

这是一个静态网站仓库，用于整理和展示：

- 国内外短信接码平台
- 临时手机号站点
- 免费 / 付费资源入口
- 优质整理帖子与扩展链接

## 目录结构

- `index.html`：主页
- `styles.css`：页面样式
- `script.js`：筛选/搜索逻辑

## 本地预览

可以直接在浏览器中打开 `index.html`，或者用本地静态服务器预览：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```
